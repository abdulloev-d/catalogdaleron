1. Загрузите всю папку на любой хостинг с HTTPS (Netlify Drop, Cloudflare Pages, GitHub Pages).
2. На планшете откройте адрес в Chrome -> меню -> "Установить приложение". Один раз с интернетом.
3. Дальше каталог работает офлайн. При каждом запуске с интернетом он обновляется сам.
4. Админ: откройте адрес#admin (например https://site.tj/#admin), измените товары, нажмите "catalog.json", замените этот файл на хостинге (и добавьте новые фото в images/).
Локальная проверка: в папке выполните python3 -m http.server 8000 и откройте http://localhost:8000
